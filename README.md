## Uso

Cada práctica se puede ejecutar con Python 3 desde la línea de comandos:

```bash
python Entregas/practica_unidad_1.py
```

## Requisitos

- Python 3.7 o superior
- No requiere librerías externas

Este repositorio agrupa los principales prácticos desarrollados durante el cursado de Programación I, con ejercicios de estructuras secuenciales, condicionales, bucles y manejo básico de datos.
